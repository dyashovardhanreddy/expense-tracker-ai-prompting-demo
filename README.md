# expense-tracker-ai-prompting-demo

Prompt Used:
Create an Expense Tracker Application
An application for tracking expenses and income from multiple sources.

Features
Users should be able to add, update, and delete expenses.
Each expense should be assigned to a category, such as Food, Groceries, Transport, or Miscellaneous. Users should also be able to create custom categories. Similarly, income should be categorized by source.
Users should be able to generate cumulative financial reports for a day, week, month, year, or custom date range (start date and end date).
Users should be able to group related expenses into collections. For example, a birthday party might involve separate expenses for food, transport, and groceries. Users should be able to tag individual expenses and associate them with a specific collection.

Technical Requirements
Use HTML, vanilla CSS, and vanilla JavaScript.
Implement smooth-scroll navigation.
Ensure the application is fully responsive on mobile devices.
Include a hero section with a gradient background.

Design Requirements
Developer-focused aesthetics: Take inspiration from GitHub and Visual Studio Code.
Dark mode support: Include a toggle in the settings to switch between light and dark themes.
Typography: Use clear, modern typography for a clean and readable interface.

Additional Requirements
Include realistic sample data to demonstrate the application's functionality.
Ensure all buttons and interactive elements are fully functional.
